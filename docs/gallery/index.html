How it was made

Compass Display is a good example of building a font from code. Each letter is a list of shapes, and the engine does the rest: it fixes contour direction, writes the TrueType and CFF outlines, adds kerning and compresses the web formats.

Want a font of your own? Start from Quill Hand in the studio on the home page, or follow the guide on turning your handwriting into a font.

fontsketch

A free, open source font maker. Draw, import or scan your handwriting and export real TTF, OTF, WOFF and WOFF2 fonts, all in your browser.

Made by Alexandre Kohler (GitHub and LinkedIn).

Built with Monsoon. Interactive parts built with Voodoo.js.

# fontsketch editor app

The browser font editor served at https://kwy404.github.io/fontsketch/app/.

- `index.html`, `app.css`: the editor shell (Monsoon 0.2.0 for components and tokens, Voodoo.js 1.0.0 for the reactive panels).
- `js/`: plain ES modules. `main.mjs` boots the app; `editor.mjs` is the canvas engine (zoom, pan, guides, tools); `panels/*.mjs` are the side panels.
- `lib/fontsketch.mjs`: the engine (core plus scan) bundled by `npm run docs:app` (`scripts/build-docs.mjs`). Do not edit it by hand.
- `templates/*.fontsketch.json`: the starter fonts, generated by `node scripts/app-templates.mjs`.
- `embed.mjs`: the drawing pad used by the landing page hero.

## Quick mode

The start screen opens with a quick font: pick a style (script, block or pixel), draw the 26 lowercase letters one by one with a faint guide letter behind the canvas, then press Finish. `js/quick.mjs` (`finishQuick`) adds the rest:

- capitals made from your lowercase (pixel letters grow by whole rows so strokes stay one cell thick), unless you drew them;
- digits, punctuation and marks from the style template (Quill Hand, Atelier Geometric or Atelier Pixel), scaled to your metrics;
- Latin-1 accented letters composed from base and mark;
- side bearings from each letter's shape (whole cells for pixel fonts).

The pixel brush (`js/pixel.mjs`) fills grid cells and keeps a pixel letter as a set of cells, so strokes and the eraser never leave the grid. Atelier Pixel, the 5 by 7 pixel template, is built from bitmaps in the same module.

## Opening the editor with a font

| URL | What happens |
| --- | --- |
| `app/` | Reopens the last project (or Quill Hand) and shows the start screen. |
| `app/#editor` | Same, without the start screen. |
| `app/#template=geometric` | Opens a template as a new project: `quill-hand`, `geometric`, `rounded`, `mono`, `pixel`, `icons`. |
| `app/#quick=script` | Starts quick mode in a style: `script`, `block` or `pixel`. |
| `app/#handoff=latest` | Opens a font handed over by another page (see below). |

### Handoff format

The page that hands a font over writes it to IndexedDB, then navigates to the editor:

- database `fontsketch-handoff`, version 1, object store `handoff` (out of line keys, created in `onupgradeneeded`)
- key: any string, normally `latest`
- value: the core `serialize(font)` JSON string (the `.fontsketch.json` project format)
- then open `app/#handoff=<key>`, optionally `&glyph=<glyph name>` to select a letter

The editor reads the key, deletes it, opens the font as a new project and selects the glyph. `embed.mjs` exports `putHandoff(key, value)` and the pad's `openInEditor()` does all of this.

## Embeddable drawing pad

```js
import { mountSketch } from './app/embed.mjs';

const pad = await mountSketch(canvas, {
  char: 'a',                                              // letter to draw first
  baseFont: './assets/fonts/quill-hand.fontsketch.json',  // optional: fills the other letters
  brush: { size: 74, pressure: true, taper: 0.35, smoothing: 0.35 },
  ink: '--ink', guide: '--line', paper: null,             // colors or CSS custom property names
  sheen: true,                                            // wet ink highlight after each stroke
  onStroke: ({ char, contours }) => {},
  onFont: ({ family, face, font, chars }) => {
    sentence.style.fontFamily = `"${family}", Georgia, serif`;
  },
});
```

The pad returns `{ char, chars, family, setChar, undo, redo, clear(all), contours(ch), svgPath(ch), toFont(), export(format), openInEditor(url), refresh(), destroy() }`. Every finished stroke is outlined with the core (`strokeToOutline`, then `removeOverlaps`), the font is compiled to TTF and loaded with `FontFace`, and `onFont` receives the new family name.

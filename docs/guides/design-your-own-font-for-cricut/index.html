To design your own font for Cricut, create the letters in a font editor, export a TTF or OTF file, install it on your computer and restart Cricut Design Space so it appears with your system fonts. With fontsketch you can scan your handwriting or import drawings for free in the browser, then shape the letters so they cut cleanly.

How Cricut uses fonts

Cricut Design Space does not import font files directly. It uses fonts installed on your computer. So the workflow is always the same: make the font, install it on the system, then pick it in Design Space.

It also helps to understand what kind of font you are making. fontsketch produces outline fonts, which is what nearly every font on your computer is. Each letter is a closed shape. That matters for each Cricut operation:

OperationWhat happens with an outline font
CutThe blade follows the outline of each letter. This is what outline fonts are made for.
Print then cutThe letter is printed filled, then cut around. Works perfectly.
Draw or penThe pen traces the outline of each letter, giving hollow letters, not a single line stroke.

If you need letters drawn with a single pen line, look for a dedicated single line font. For cutting vinyl, iron on, cardstock and stickers, an outline font is exactly what you want.

Step 1: create your letters

Pick the route that suits your style:

  • Your handwriting: print the fontsketch handwriting sheet, fill it with a thick felt tip pen, take a photo. The full walkthrough is in turn your handwriting into a font.
  • Hand lettering you drew: trace a high contrast image or import SVG. See convert an image to a font.
  • Drawn directly: use the brush for loose strokes or the bezier pen for clean shapes.

For Cricut, write or draw with a thicker pen than usual. Thin lines that look pretty on paper become fragile strips of vinyl that tear while weeding.

Step 2: make the letters cut friendly

A font that looks great on screen can still be painful to cut. Fix these in the editor before exporting:

  • Thicken thin parts. As a rough guide, keep strokes at least 1.5 to 2 mm wide at the size you plan to cut. Hairlines in script fonts are the usual weak spot.
  • Open tiny counters. The holes in e, a and o become tiny pieces to weed. Make them generous.
  • Remove overlaps. If a stroke crosses another, as in t or x, run overlap removal. Otherwise Design Space may show cut lines inside the letter.
  • Correct contour direction, so counters are holes and not filled shapes.
  • Simplify outlines. Traced letters can have hundreds of tiny segments. Simplifying gives smoother cuts and fewer jagged edges.
  • Delete specks. A stray dot from the scan becomes a tiny confetti piece on the mat.

Step 3: plan connected script letters

If your font is cursive, the letters need to join when typed. Draw each lowercase letter so its entry and exit strokes leave at the same height, about halfway up the x-height is common. Then set the side bearings so the exit stroke of one letter slightly overlaps the entry of the next. A small overlap is better than a gap, because Weld can merge an overlap into one clean shape but cannot bridge a gap.

Kerning pairs help with awkward joins such as o followed by another letter, where the exit stroke is high. The handwriting converter guide has tips for writing letters that connect consistently.

Step 4: export the font

Export as TTF, the most widely compatible format on both Windows and macOS. OTF also works. Hinting does not matter for cutting, so you can export without it. Give the font a clear name so you can find it in long font lists.

Step 5: install the font

On Windows

  1. Close Cricut Design Space.
  2. Find the TTF file in your Downloads folder.
  3. Right click it and choose Install, or Install for all users if you are on a shared computer.
  4. Alternatively, open the file and click Install in the preview window.

On macOS

  1. Quit Cricut Design Space.
  2. Double click the TTF file. Font Book opens a preview.
  3. Click Install Font.
  4. If Font Book reports a warning, read it, then choose to install if you are satisfied it is your own file.

Step 6: use your font in Design Space

  1. Open Design Space and start a new project.
  2. Add a text box and type your text.
  3. Open the font list and filter by system fonts to find yours quickly.
  4. For script fonts, reduce letter spacing until the joins overlap.
  5. Select the text and click Weld to merge letters into one shape.
  6. Choose your operation: basic cut, print then cut, or pen.

Weld is permanent for that text object, so keep an unwelded copy hidden on the canvas in case you need to edit the wording.

Sizing text for cutting

Font size in Design Space is not the same as size on paper, so measure the actual letters on the canvas. As a starting point for adhesive vinyl, keep lowercase letters at least 1.5 cm tall for a script font and 1 cm for a bold sans. Iron on vinyl and glitter materials are thicker and weed less easily, so go larger. Cardstock tolerates finer detail than vinyl but tiny counters still tear.

If you plan to cut small text often, design the font for it: a large x-height, open counters and sturdy joins. A delicate script made for big wall decals will not survive at mug label size. Some makers keep two versions of the same handwriting, a regular one and a bolder one tuned for small cuts.

Updating your font later

When you improve the font and reinstall it, uninstall the old version first, and restart Design Space. Systems and apps sometimes cache fonts, so a changed file with the same name can keep showing the old shapes. If changes do not appear, restart the computer. For bigger changes, consider a new name like MyHand v2.

Cricut font checklist

  • Letters drawn or written with thick strokes
  • Thin parts thickened, counters opened, specks deleted
  • Overlaps removed and contour directions corrected
  • Script letters overlap slightly at the joins
  • Exported as TTF, installed, Design Space restarted
  • Script text welded before cutting
  • Unwelded copy kept for edits

Questions people ask

Can I make my own font for Cricut for free?

Yes. fontsketch is free and runs in your browser. You can turn your handwriting or drawings into a TTF font, install it on your computer, and Cricut Design Space will list it with your other installed fonts.

Why is my new font not showing in Cricut Design Space?

Design Space reads installed fonts when it starts. Close it completely and reopen it after installing. If it still does not appear, check that the font installed correctly in your system font list and look under the system fonts filter.

Can I use my font with the Cricut pen to write instead of cut?

You can, but fontsketch makes outline fonts, so the pen traces around the outline of each letter rather than writing a single line through it. For a filled look, choose a thick pen and a bold font, or use print then cut instead.

How do I keep cursive letters connected when cutting?

Design the letters so their joining strokes overlap a little, adjust letter spacing in Design Space until they touch, then select the text and use Weld. Welding merges the letters into one shape so the cut does not slice through the joins.

What is the best font format for Cricut?

TTF and OTF both work because Design Space uses fonts installed on your system. TTF is the most widely compatible choice.
